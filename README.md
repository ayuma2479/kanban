# 営業案件ボード

営業案件を「リード → 商談 → 契約」の3段階で管理し、右端の「失注」列で失注案件を保管するFlutterアプリです。

| 列 | 管理する状態 | 案件の例 |
| --- | --- | --- |
| リード | 問い合わせや紹介で接点ができた見込み顧客 | 株式会社青空：サービス導入の問い合わせ |
| 商談 | ヒアリング・提案・見積もりを進めている案件 | 株式会社みどり：業務改善ツールの提案 |
| 契約 | 契約が成立した案件 | 株式会社ひかり：年間プランの契約 |
| 失注 | 契約に至らず終了した案件 | 株式会社あかね：予算の都合で見送り |

案件名を入力して「リードに追加」を押すと登録できます。カードのボタンで次の段階に進め、鉛筆アイコンで案件名を編集できます。ごみ箱アイコンを押すと右端の「失注」列へ移動し、案件名と最終アクション日を保持します。失注案件にはごみ箱・移動ボタンを表示しません。データは端末に保存されます。既存データの列は、左からリード・商談・契約として引き継ぎます。

起動：`flutter run`

案件には「最終アクション日」を任意で記録できます。追加・編集画面のカレンダーから実際に連絡や提案を行った日を選択すると、カードに表示されます。編集画面の×ボタンで未設定に戻せます。列の移動では日付は変更されません。
